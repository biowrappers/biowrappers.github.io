BioWrappers is a collection of lightweight wrappers around common bioinformatics APIs and tools to enable their use workflows.

<!--more-->

This idea was created out of the need for having simpler ways to integrate common APIs into other bioinformatics tools or workflows. It was also intended to make it easier for people to access APIs if they had little or no experience doing so using API endpoints.
